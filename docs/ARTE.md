# Arte original

Se utilizó la herramienta integrada **ImageGen**, modo de generación nueva, sin referencias ni edición de imágenes. Los cinco PNG finales están incluidos en `client/public/assets`. Las capturas de verificación del sitio se guardan aparte en este directorio.

| Archivo                              | Uso                              |
| ------------------------------------ | -------------------------------- |
| `client/public/assets/nexus.png`     | Hero, Nexus y pantalla de acceso |
| `client/public/assets/emberfall.png` | Emberfall y Echoes of Aether     |
| `client/public/assets/velocity.png`  | Velocity 2099 y Neon Drift       |
| `client/public/assets/titan.png`     | Titan Protocol                   |
| `client/public/assets/odyssey.png`   | Astral Odyssey y Void Command    |

Son ilustraciones para videojuegos ficticios. Dos productos del seed pueden compartir una ilustración; el administrador puede reemplazarla por una ruta local o una URL HTTPS. Los iconos de interfaz provienen de Lucide; el logotipo y el fallback son SVG locales.
